# arthurfou.github.io

Source of my personal site: **[arthurfou.github.io](https://arthurfou.github.io/)**.

I am an engineering student at École polytechnique and Mines Paris PSL, working on
AI for robotics: perception, event cameras, computer vision and reinforcement learning.

## About the site

Hand-written HTML, CSS and vanilla JavaScript, with no framework and no build step.
The header is a small event-camera simulation: moving edges, and the visitor's cursor,
emit positive and negative events on a canvas (`assets/js/events.js`).

To run it locally:

```bash
python3 -m http.server 8000
```

then open http://localhost:8000.
