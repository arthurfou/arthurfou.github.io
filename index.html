Selected work

Mar–Jul 2026 IPAL, CNRS–NUS, Singapore

3D mapping from a single event camera, with moving objects

Event cameras report per-pixel brightness changes asynchronously instead of frames, which makes them fast and robust to motion blur — and awkward for reconstruction methods that assume a static scene. I worked on handling dynamic objects so that the recovered geometry stays faithful when people and obstacles move through the field of view. The target application is a drone carrying one event camera, assisting a person with reduced mobility.

Event-based vision, 3D reconstruction, Python, PyTorch

Nov–Dec 2025 Data challenge, École polytechnique

Telling influencers from observers on social media

Binary classification of user roles from tweet content. I ran the exploratory analysis on feature distributions and class imbalance, then compared transformer encoders (BERT, CamemBERT, BERTweet) against classical classifiers and smaller neural baselines. The best model reached 85% accuracy on the Kaggle leaderboard.

PyTorch, Hugging Face, scikit-learn

Easing peak-hour congestion in paramedic call centres

A year-long project with a paramedics research department. We built a retrieval-augmented prototype to help operators during surges, and evaluated how it could realistically sit inside an existing dispatch workflow rather than beside it.
